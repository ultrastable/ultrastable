# Ultrastable git bundles

Real git history for the seven `ultrastable` org repos (site, docs, platform, ip, business, seed, .github), made because the GitHub repos don't exist yet. Each `.bundle` is a full repo: `git clone docs.bundle docs` works anywhere.

Once the empty private repos exist on GitHub, a Claude session attaches them and pushes, or `./push-all.sh` does it from any machine signed in to GitHub. The `ip` bundle includes the provisional draft under `ip/provisional/`.

Index of everything: `docs/roadmap.md`, section "Where everything lives".
