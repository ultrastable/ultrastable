# Staged site copy

**Ultrastable is the foundation for any autonomous system.**

A system is autonomous if it has self-referential loops and the ability to close them. Knowing without being able to act is useless, so the system is privileged to close its own loops (`python3 -m foundation loops --verify`).

**Ultrastable runs on itself.** Its own planning, work tracking and reporting are run by the system it gives to others.

Status: draft; the project is open and the Ultrastable License governs use. Voice: plain, calm, no hype, claims labeled RUNNING, BUILT or PLANNED. This is about an autonomous system for any kind of organization, not research. QNFO appears only as the proof case.

## Headline
**Software that stays up.** Autonomous software development, built to keep running.

## One-paragraph pitch
Start with an idea. Ultrastable sets up the organization around it: it builds the product, then keeps working on it. It notices what is missing, assigns the work to virtual managers and staff that run continuously, checks its own results, and improves itself. You can give direction whenever you like; you never have to. You do not need a development team to begin.
