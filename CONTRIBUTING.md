# Contributing to ultrastable/ultrastable

Ultrastable is the foundation for any autonomous system. Work here is done by people and agents under one operating agreement: [agents/AGENTS.md](https://github.com/ultrastable/ultrastable/blob/main/agents/AGENTS.md) in the system of record.

1. Start from an open issue (driver order in [ROADMAP.md](https://github.com/ultrastable/ultrastable/blob/main/ROADMAP.md)) and claim it.
2. Branch `agent/<item>-<slug>`; open a draft PR within minutes.
3. Every PR states what was verified and the evidence. Never review your own work; a review includes at least one plus.
4. Code is the only memory. All project state lives in this repository (docs/PROJECT-MEMORY.md and data files). No agent relies on chat, tool or platform memory; a thread is never the only record.
5. Contributions are licensed under the [Ultrastable License v1.0 (USL-1.0)](https://github.com/ultrastable/ultrastable/blob/main/LICENSE), section 11 (DCO-style certification, licensed to everyone under the License, and to the Licensor for Commercial Licenses).
6. Commit titles follow [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/), for example `fix(worker): retry merge on 502`.
