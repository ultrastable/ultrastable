# org-repos

Interim monorepo home for the planned `ultrastable` org repos (site, docs, platform, ip, business, seed, .github) until each exists as its own private repo. Each subfolder is the repo's content; `_bundles/` holds real git history for each (`git clone _bundles/docs.bundle`), and `_bundles/push-all.sh` pushes them once the repos exist. Issues to file: `docs/issues/*.json`. Keep private until the provisional patent is filed.
