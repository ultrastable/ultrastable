# Overview

Ultrastable is an autonomous development platform that runs an organization's portfolio of work with virtual managers and virtual staff. It generalizes the QNFO fleet, which already runs this way on Cloudflare.

Three ideas carry it:

1. **Virtual staff in an org structure.** A portfolio manager, project managers, product managers and staff agents, each owning one level of the work, the way a real organization is staffed.
2. **Closed feedback loops.** Every action is predicted, executed, verified and compared to its prediction. Outcomes feed a trust ledger that decides how much autonomy each agent and action class gets next.
3. **Plussing.** Improvement is planned work, not a leftover. Every finished item proposes the next way to make it better, and capacity is reserved so the system does not collapse into bug fixing.

People set direction and approve the steps that can't be undone. Everything else the virtual staff carries end to end.
