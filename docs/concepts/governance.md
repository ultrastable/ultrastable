# Governance: what people decide

- **Direction.** People set objectives; managers infer priorities from them and from people's revealed choices.
- **The approval gate.** An agent stops only for steps that are both irreversible and identity-bound (spending money, signing, destroying data with no backup, outside communications). It first tries to make the step reversible.
- **Override.** A person's override always wins and is recorded.
- **Audit.** Every decision, prediction, outcome and trust change is logged and reviewable.
