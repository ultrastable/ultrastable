# A path mention in a document or an issue is not consumption

Date: 2026-11-12
Kind: lesson

Counting a document as used because any file names its directory gave 2 orphans of 396; requiring an exact path in code or data, an import, a generator or a registry row whose consumer contains a needle gave 248. Consumption is verified, not inferred; the knowledge tier is the weakest tier and is reported separately so it cannot hide orphans.
