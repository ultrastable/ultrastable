# Lessons

Write-back target for what sessions and loops learned: decisions, lessons, open loops and term changes land here (or in `docs/decisions/`, `docs/issues/`, `doctrine/glossary.json`) before a session ends. Add one with `python3 -m foundation writeback record --kind lesson --title "..." --body "..."`. Files here are linted by the recognition lint (`python3 -m foundation kernel --lint`).
