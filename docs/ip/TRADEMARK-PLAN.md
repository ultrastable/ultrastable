# Trademark search and registration plan (FUND-8, issue #110)

Working draft for counsel review. Not legal advice. Builds on [IP-8 clearance notes](IP-8-trademark-clearance-notes.md).

## Position
Preliminary web search found no ULTRASTABLE software mark, but aggregators are incomplete, so this is not clearance. "Ultrastable" is laudatory for stability software (descriptiveness refusal risk), and the ULTRA- prefix is crowded.

## Plan
| Step | Who | Trigger | Done check |
|---|---|---|---|
| 1. Official USPTO search for ULTRASTABLE, ULTRA STABLE, ULTRA-STABLE and phonetic variants, classes 9, 42, 35 | Owner or counsel (identity-bound: uses the owner's account) | Entity formed (#105) | Result pasted into IP-8 notes |
| 2. EUIPO and WIPO search | Counsel | Step 1 clear | Result recorded |
| 3. Descriptiveness view; word mark vs logo or composite | Counsel | Step 1 and 2 | Decision recorded in IP-8 |
| 4. File (owner signs, pays) | Owner | Decision and entity | Serial number logged in IP-REGISTER |
| 5. Fallback names screened the same way | Staff | Step 1 shows a conflict | Shortlist with search results |

## Defaults in effect
No filing. Product name used as a common-law mark only. Nothing about the filing or patent is published before the provisional (see CONFIDENTIALITY).

## Closing probe
`docs/ip/IP-REGISTER.md` carries a trademark row with a serial number, or IP-8 records "defer" or "skip" with counsel's reason.
