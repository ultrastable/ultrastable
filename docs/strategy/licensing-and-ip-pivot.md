# Decision: license instead of patent (2026-11-11, Rowan)

- A patent is not the route: use with QNFO is already a kind of public disclosure, and the QNFO repo has been public since 2026-08-10. (Whether that bars filing is an attorney question; it is no longer a blocker because filing is dropped.)
- Protection is a hybrid license: free for non-commercial use, commercial use needs a written license and shares revenue with the Licensor. Draft: `seed/LICENSE` (UULA v1.0), plain summary `seed/LICENSING.md`. Adapted in structure from the QNFO ULA v2.1; the QNFO text itself was not available to this session, so the attorney should reconcile.
- The code base stays public-intended, not private. **Nothing is made public until the license is attorney-reviewed and the owner signs off.**
- `ip/` is repurposed: invention disclosure and provisional draft become **architectural specifications** (dated documentation of the design). Filing items in the roadmap (IP-1 to IP-8) are superseded; the confidentiality-until-filing rule is replaced by "nothing public until license reviewed".
- Owner-only: legal entity, licensor contact, commercial fee model, signature.
