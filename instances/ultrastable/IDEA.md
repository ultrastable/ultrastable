# Idea

The foundation for any autonomous system: virtual managers and staff, closed loops, plussing and earned-trust autonomy, running its own roadmap, issues, probes and metrics from the same code it gives every customer.

# System test

- Loop: metrics breach, a remedy item is filed, an agent ships it, a probe verifies it live
- Measure: ticks per hour, items closed per week, verified outcomes per week, metrics in breach (target 0)
- Upkeep: failures, drift and roadmap items arrive every day
- Run cost: 25 USD a month for the back end
