# Objection handling

*Prep notes. Answers are speakable; "Careful" lines are notes for the speaker.*

| Objection | Answer  | Careful |
|---|---|---|
| "Five companies already do this." | True of the headline. The difference is how work is managed; judge by a 30-day pilot on your project. | Do not describe mechanisms. |
| "Why would anyone pay if there's a free open-source rival?" | Hosted, supported, and better managed beats self-assembly for most teams; same as other open infrastructure. | Do not promise features not built. |
| "You're a solo inventor." | Yes, and I'm looking for the business partner. The system carries much of the operation. | Don't oversell autonomy: financial back-end doesn't exist. |
| "Where's the revenue?" | There isn't any yet; we are recruiting design partners. | Never imply revenue. |
| "Models will absorb this." | Models do tasks; organizations need management across tasks, models and clouds. | |
| "Is it secure with agents acting?" | Secrets are by name only; narrow interrupt gate; every action recorded. | Do not give architecture. |
| "Show me the code." | The repositories are open; start at the README. | Say which parts are specification and which are running code. |
| "How is it protected?" | The code is open; the Ultrastable License governs use. | Never characterise QNFO's public repo beyond: separate project, own licence. |
| "Why open source then?" | Trust, distribution and funding access; commercial layer sustains it. | The Ultrastable License governs use. |
| "Why not just join an accelerator?" | Considering; public demo days are on the plan. | Do not promise a date. |
| "Local or cloud?" | Both planned; hosted is the default, self-hosting keeps data with you. | |
| "What if the agent makes a costly mistake?" | It must be able to undo, or it stops and asks; irreversible identity steps stay with the owner. | |
| "Is this just QNFO?" | No: separate product and brand; QNFO is the first test case. | Never share QNFO figures. |
| Grant reviewer: "Where's the community?" | First release starts it; plan in the governance file; a pilot counts as adoption evidence. | |
