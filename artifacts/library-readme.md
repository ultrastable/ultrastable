# ultrastable (consolidated local copy)

Single directory holding everything produced so far. Canonical home is the GitHub org `ultrastable`; this folder is the staging copy until the repos are pushed.

- `repos/` all seven repo working trees (site, docs, platform, ip, business, seed, .github)
- `git-bundles/` real git history per repo + `push-all.sh`
- `patent-working-copy/` provisional patent working files (also in `repos/ip/provisional/`)
- `agents-seed/` agent instruction and role files from the seed
- `records/` notes on what each thread produced
Copy of this folder as one archive: `/mnt/project-files/ultrastable.tar.gz`
