# Security policy for ultrastable/site

If you found a vulnerability in anything Ultrastable runs (https://ultrastable.io or a pilot deployment), email **pilot@ultrastable.io** with the subject `SECURITY`. Include what you saw, where, and how to reproduce it.

- We acknowledge within two working days.
- Give us a reasonable window to fix before disclosing.
- Do not access data that is not yours and do not run denial-of-service tests.
- Never post secrets or exploit details in a public issue.

Where that mailbox is read: [docs/ops/CONTACT.md](https://github.com/ultrastable/ultrastable/blob/main/docs/ops/CONTACT.md).
