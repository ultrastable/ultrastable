# core/airouter

AI-ROUTER-1. Free Workers AI first, cache and dedupe, quality gate, paid escalation only inside a hard monthly cap (default 0), every call recorded and fed back into routing. See the header of `index.js`. Tenants pass `db`, `ai`, `models` and `config`; a paid model is a `run()` function the tenant binds, so the router never holds a key. Retirement: when a call fails with error 5028 or a message saying the model was deprecated, the model is left out of routing for `RETIRE_MS` (seven days, table `airouter_retired`) and then tried once more. A call that never reached a model (a deprecation, a spend-governor refusal, the subrequest cap) costs 0 neurons and 0 USD. The seed kernel carries an unchanged copy of this file.
