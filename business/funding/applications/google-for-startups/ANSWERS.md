# Google for Startups Cloud Program: answers (generated from packet.json)

Status: drafted. Terms verified 2026-11-10 at https://cloud.google.com/startup/apply.

## What does your company do?
Ultrastable is an autonomous system that sets up and runs any organized effort from one idea, here a company. It sets up and then continuously improves the development, branding, business planning and marketing, with AI managers and staff doing the routine work and people approving only the steps that cannot be undone.

## Stage
Early stage with a working prototype. It currently runs the founder's own projects; there are no outside customers yet and design-partner pilots are the next step.

## Business model
Planned subscription per organization plus pass-through usage. This is a plan, not an established revenue stream.

## Funding raised
None. Preparing for a pre-seed round.

## Team
One founder; the product runs much of its own operation.

## How will you use Google Cloud?
Today the working system has been demonstrated on Cloudflare. Ultrastable is built with a portable core and swappable cloud adapters, and we are willing and able to run it on Google Cloud if funding is available to do so. Credits would fund a Google Cloud deployment: Cloud Run and Cloud Scheduler to run the managers on a heartbeat, Cloud Storage and Secret Manager for records and credentials, then Cloud SQL and Vertex AI (Gemini) as usage grows.

## Why Google Cloud?
Customers want a choice of cloud. A Google Cloud deployment gives them one, and Gemini models offer a second model family for the work and for independent review of the work.

## Cloud status (accuracy statement)
Demonstrated on Cloudflare. A Google Cloud adapter is not yet running in production; running on Google Cloud depends on funding being available.
