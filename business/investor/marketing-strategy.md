## 2. Positioning

One line : **AI agents are cheap. Managing them isn't. Ultrastable is the manager.**
Category: the self-governing layer around the coding agents a team already uses. Not another agent, not only a gateway (product-and-positioning.md section 8).
Why we win (competition plan, 03): autonomy that is earned, one narrow interrupt gate, planned improvement. Never lead with "AI agents that run your company": five other products say it (Paperclip, Cofounder.co, Polsia, NanoCorp, agent.ceo per the repo's competition file, checked 2026-11-10).

## 4. Messaging pillars

1. **Managed, not just assisted.** Backlog, assignment, independent check, four-line weekly report.
2. **Earns its freedom.** Starts by asking; asks less as it proves itself.
3. **Interrupts only for what can't be undone.** Short list the customer controls.
4. **Plans improvement.** A protected share of time for making things better, not endless bug fixing.
5. **Works with the agents you have.** Claude Code, Codex and similar CLIs; cloud-agnostic core.
6. **Auditable.** Every item leaves with a recorded disposition.

Proof sentence : "We run our own work on it." Numbers come from the live dashboard.

## 11. Objection handling

| Objection | Answer |
|---|---|
| "Devin / Cursor / Claude Code already do this" | They are the workers; we manage them. |
| "Paperclip is free" | Org charts are easy; knowing when an agent can act alone is hard. Ours earns it. Open core is a `[FOUNDER CONFIRM]` / question. |
| "I'd never let AI act without approval" | It starts by asking about everything; you set the short list it always asks about. |
| "Big labs will build this" | Maybe a version. We are model- and cloud-agnostic. The method is open and the licence governs its use. |
| "You're a solo founder" | True, and a risk we state openly; the product is the team, and funds go to a founding engineer. |
| "What if an agent breaks something?" | Independent check on every result, irreversible steps go to a person, reversible ones can be rolled back. |
| "Is the demo real?" | The shipped demo uses simulated agents to show the control loop; command and Anthropic adapters exist but are not yet proven in production. |
| "Show me numbers" | From the live dashboard, labelled self-measured. |
