# Competitor map

*Internal prep. Public facts only, checked 2026-11-10 by the research staff; full landscape and sources in [plan/03-competition.md](../plan/03-competition.md). Re-checked quarterly (see MAINTENANCE.md).*

| Layer | Examples | Strength | Where Ultrastable differs | Likely stance |
|---|---|---|---|---|
| AI workers | Devin (Cognition), Cursor, Claude Code, OpenAI Codex, Google Jules, GitHub Copilot agent, Factory, Replit Agent | Do the work; heavily funded | We manage the work and the workers; we are model-agnostic | Substrate and channel, not rival |
| "Run a company with agents" | Paperclip (MIT open source), Cofounder.co, Polsia, NanoCorp, others | Same headline | Management quality: narrow interrupts, earned independence, planned improvement | Closest rivals; Paperclip is free, so our edge must be quality and hosted service |
| Agent frameworks | CrewAI, LangGraph, Microsoft Agent Framework, OpenAI Agents SDK, Claude Agent SDK, MetaGPT, ChatDev | Toolkits for builders | Opinionated organization kit on top | Builders could assemble parts; they are prior art for role names |
| Enterprise agent platforms | Salesforce Agentforce, ServiceNow, Google Gemini Enterprise, AWS Bedrock AgentCore, Microsoft Copilot Studio; Zapier, n8n, Lindy, Relevance AI | Distribution, trust | Cross-vendor, any cloud | Future channels or acquirers |
| Open foundations | Agentic AI Foundation (Linux Foundation) | Neutral home, interoperability standards | Possible home, not a rival | Partner |

Talking rules: never lead with "AI agents run your company"; lead with the manager problem. Do not disparage named products. Quote no competitor figures externally.

Acquirer/partner target list (do not contact before filing): cloud providers with agent platforms, developer-tool vendors, agent-platform vendors above.
