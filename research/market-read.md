# Market read (web search 2026-11-10; vendor blogs and aggregators, so indicative, not verified)
- Cloud coding agents (Devin, OpenAI Codex cloud, Factory, GitHub Copilot coding agent) are sold as executors a person assigns work to. Governance (SSO, RBAC, audit logs, sandboxing) is now a standard buying criterion; Gartner named Codex a Leader in its Enterprise AI Coding Agents Magic Quadrant (April 2026, per one source). Unconfirmed: Devin revenue figures, Cognition funding (USD 1B at USD 26B, June 2026, per one source).
- Control planes and gateways for coding agents: Fiddler (acquired Lumeus), OpenHands Agent Control Plane, Coder AI governance stack, Bifrost. They cover cost, access, audit. One analyst brief: agent governance roughly USD 1.0-1.5B in 2026, cross-vendor governance immature.
- Not found in any result: automatic revert of agent-made changes, or a system that chooses its own work. That is the claimed gap.
