# ultrastable/ip (owner only)

Historical working files for a patent application that was never filed.

- [invention-disclosure.md](invention-disclosure.md): what the invention is, in enough detail to support claims.
- [evidence-log.md](evidence-log.md): dated record of conception and reduction to practice (commits, deployments).
- [prior-art.md](prior-art.md): known related work and how this differs.
- [provisional/](provisional/): provisional specification, figures, drawings and filing checklist.

Timing note: a public page, post or demo describing the invention counts as a disclosure, so file the provisional before the site or docs describe the mechanisms. Specific timing questions are for the patent attorney.

This is a working draft prepared with Claude, not legal advice. Have a patent attorney or agent review before filing.
