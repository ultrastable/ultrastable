# ABSTRACT

A system operates an organization through a hierarchy of virtual staff agents, each defined by a persona record with a role, a program, metrics and an enumerated set of permitted operations. On ticks a portfolio-manager agent allocates focus capacity across programs by risk, and program-manager agents rank work and write priority records that an execution queue uses to dispatch work to executor processes; each operation is recorded with its prior value. Each decision carries a machine-readable prediction that is scored; a trust ledger per surface and action class maps verified outcomes to an autonomy ladder that selects each action's execution path. A plus loop reserves capacity for evidence-driven, additive changes to working products and keeps a change only when its outcome improves without guard regression. Only irreversible, identity-bound steps reach the human principal.
